# Algorithmic-Strategy-Backtester
Algorithmic Trading Backtester 📈 – Python-based backtesting engine for evaluating trading strategies (Moving Average Crossover, RSI, Bollinger Bands, Momentum) on historical stock data. Features real-time data from yfinance, performance metrics (Sharpe ratio, drawdown, volatility), commission/slippage modeling, and interactive Streamlit dashboard.
